🔧 PC Lento? Diagnóstico Rápido

Antes de formatar ou comprar um PC novo, faz este diagnóstico em 5 passos:

Passo 1: Abre o Task Manager (Ctrl+Shift+Esc) e verifica o que está a consumir CPU, RAM e disco.

Passo 2: Verifica os programas que arrancam com o Windows. No Task Manager → Startup, desativa tudo o que não precisas.

Passo 3: Verifica o espaço em disco. Se tens menos de 10% livre no disco C:, o Windows vai sofrer. Usa Limpeza de Disco ou o comando cleanmgr.

Passo 4: Verifica a temperatura. Programas como HWMonitor mostram se o CPU está a sobreaquecer (acima de 80°C é preocupante).

⚠️ Se o disco for HDD e não SSD, esta é quase sempre a causa da lentidão. Trocar para SSD é a melhor atualização que podes fazer — o PC fica como novo!

Passo 5: Faz um scan com o Windows Defender ou Malwarebytes para descartar malware.
